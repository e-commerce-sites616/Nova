# Claude handoff — NOVA

You are receiving a working starter project, not a finished implementation.

## First
1. Inspect the entire repository and run it locally.
2. Run `npm install`, then `npm run dev`.
3. Check the browser console and fix any starter issues before expanding.
4. Review `README.md` and the current product data and design tokens.

## Your assignment
Transform this foundation into the complete NOVA premium technology e-commerce experience described in the user's creative brief.

The chosen direction is:
- Brand: NOVA
- Tagline: Technology, Reimagined.
- Category: premium consumer technology
- Atmosphere: dark luxury
- Motion: cinematic and immersive

The existing files are a starting point only. You have creative freedom to restructure, refactor or replace implementation where doing so materially improves quality. Preserve useful working behavior.

## Priorities
- Make the product imagery and presentation exceptional.
- Establish a coherent, reusable motion system.
- Make scroll storytelling feel art-directed, not like a page full of random animations.
- Build complete collection and product-detail experiences.
- Improve shopping interactions, cart and responsive navigation.
- Ensure mobile is deliberately designed, not merely compressed desktop.
- Keep accessibility, performance and reduced-motion support in scope.

Do not mistake the current four-product demo catalogue or homepage sections for final requirements. Expand and improve them.

Do not spend all the effort on the hero. Give collection pages, product details, cart and mobile equal design attention.

Before large changes, explain your proposed architecture and creative direction briefly. Then implement, test and polish the complete experience.

The user explicitly wants you to improvise intelligently and introduce original ideas that strengthen NOVA's identity.
