# NOVA — Technology, Reimagined.

Static, front-end-only premium tech storefront. Vite + vanilla JS + GSAP/ScrollTrigger. No backend, no real payments.

## Run
```
npm install
npm run dev
```
Open the printed URL. Production check: `npm run build && npm run preview`.

## Structure
- `src/main.js` — hash router (`#/`, `#/shop`, `#/product/:id`, `#/wishlist`, `#/checkout`), page transitions, global actions
- `src/motion/index.js` — motion system: easing/duration/stagger tokens, `data-reveal`, `data-stagger`, `data-lines`, `data-parallax`
- `src/art/products.js` — finish tones + original inline SVG renders (used as a fallback if a photo fails)
- `src/assets/products/` — studio photography, generated by `npm run photos:prepare` (see its README)
- `src/data/products.js` — catalogue (12 products, categories, options, specs, availability)
- `src/store/` — cart (localStorage) and wishlist (localStorage)
- `src/views/` — home, shop, product, wishlist, checkout
- `src/components/` — product card, header/footer/bag drawer/search
- `src/style.css` — design tokens and all styling

## Motion rules
Only transform, opacity and clip-path are animated. Everything is skipped under `prefers-reduced-motion`.
The flagship spotlight pins on desktop only; on tablet and mobile it stacks.

## Demo notice
Checkout is a demonstration. No payment is processed and card details are never stored.

## Video
Videos live in `public/video/` (generated from the raw recordings in `/videos` by `npm run videos:prepare`, see `public/video/README.md`).
- **Home, scroll-scrubbed** (`src/components/scene.js`): the case film (`#reveal`) and the finish chooser (`#colours`). They use native `position: sticky`
  inside a tall section; scroll progress drives `video.currentTime`. They run at every screen size (phones get a portrait layout: film on top, copy
  underneath). Only with `prefers-reduced-motion: reduce` do they become normal blocks that show a poster / loop quietly. The finish chooser holds on each finish and its chips / "Shop in <finish>" link follow along (`/#/product/aura-buds?finish=moss`).
- **Home, statement:** a muted looping lifestyle film that plays only while visible; sound is opt-in.
- **Product pages:** add `film: { name, title, text }` to a product in `src/data/products.js` to get a player (poster first, sound on play).
- Serve with a host that supports HTTP range requests (Vite and every real host do) or scrubbing cannot seek.
