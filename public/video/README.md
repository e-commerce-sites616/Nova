# Video

Generated by `scripts/prepare-videos.py` (`npm run videos:prepare`) from the raw screen recordings in `/videos`.
Do not edit by hand - change the manifest (`JOBS`) in the script and re-run it.

| File | Used for |
|---|---|
| `buds-case.mp4` | Home - scroll-scrubbed "case" scene (no audio, keyframe every 2 frames) |
| `buds-colours.mp4` | Home - scroll-scrubbed finish chooser (captions cropped off, holds on each finish) |
| `lifestyle-film.mp4` | Home - muted looping background of the closing statement (sound is opt-in) |
| `aura-one-film.mp4` | Product page film - Aura One |
| `aura-buds-film.mp4` | Product page film - Aura Buds |

What the script does: removes the recorder's mouse cursor (template-matched and inpainted), trims brand outros and the
"Stop recording" tooltip, crops burned-in captions, re-encodes to H.264 with faststart, and writes a `.jpg` poster for each.
The raw recordings are retail brand films and show other companies' logos (see the photography README).

## Running the pipeline on Windows
`npm run videos:prepare` (and `photos:prepare`) find Python for you (`py -3`, `python3` or `python`). You need Python 3 from python.org
(tick "Add to PATH"), `pip install pillow numpy scipy opencv-python`, and ffmpeg on your PATH (`winget install Gyan.FFmpeg`), then a new terminal.
Put the raw recordings in a `videos/` folder at the project root first.
