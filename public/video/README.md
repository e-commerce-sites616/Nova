# Video

Generated by `scripts/prepare-videos.py` (`npm run videos:prepare`) from the raw screen recordings in `/videos` (git-ignored).
Do not edit by hand: change the manifest (`JOBS`) in the script and re-run it.

| File | Used for |
|---|---|
| `buds-case.mp4` | Home: scroll-scrubbed "case" scene (no audio, keyframe every 2 frames) |
| `buds-colours.mp4` | Home: scroll-scrubbed finish chooser (captions cropped off, holds on each finish) |
| `lifestyle-film.mp4` | Home: muted looping background of the closing statement (sound is opt-in) |
| `aura-one-film.mp4` | Product page film: Aura One |
| `aura-buds-film.mp4` | Product page film: Aura Buds |

The script removes the recorder's mouse cursor (template-matched and inpainted), trims brand outros and the "Stop recording" tooltip,
crops burned-in captions, re-encodes to H.264 with faststart and writes a `.jpg` poster for each.
